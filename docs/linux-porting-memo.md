# MatrixClass Linux 版待办备忘

> 更新时间：2026-11-19
>
> 本文记录 Linux 版当前尚未完成、尚未实机验证或暂时不能承诺生产可用的事项。完成一项后更新复选框、验证环境、验证命令和对应 Git commit。

## 当前基线

已完成 Linux 交叉构建目标：

- `linux/amd64`
- `linux/arm64`
- `linux/loong64`

已完成基础能力：

- Go + MyGo 原生 UI 构建。
- KCP/SMUX 局域网通信。
- 文件分发、课堂消息、作业和基础课堂控制。
- Linux Shell 远程命令执行。
- XDG `.desktop` 应用列表解析。
- X11 屏幕采集初版。
- X11 远程鼠标、键盘和滚轮输入初版。
- Linux 音频命令适配：`pw-cat`、`parec`、`arecord`、`paplay`。
- Linux 进程管理、电源控制和桌面锁屏初版。
- Linux 三架构构建脚本、安装脚本和 `tar.gz` 发布包。
- GPL/LGPL/AGPL 依赖扫描通过。

## P0：必须完成后才适合生产发布

### 1. Wayland 屏幕采集

- [ ] 实现 `xdg-desktop-portal + PipeWire` 屏幕或窗口采集。
- [ ] 支持用户选择屏幕、窗口和采集区域。
- [ ] 保存并恢复已授权的 Portal session handle。
- [ ] 处理用户取消授权、授权过期和桌面会话切换。
- [ ] 处理 PipeWire 节点断开、重连和分辨率变化。
- [ ] 在 GNOME、KDE、UKUI、DDE 等桌面环境分别验证。
- [ ] 未授权时继续显示明确状态，不得伪造合成画面为真实监控画面。

完成标准：Wayland 环境下学生端能真实采集屏幕，教师端连续监控至少 30 分钟不丢帧、不永久卡死；授权取消后 UI 显示可恢复操作。

### 2. X11 屏幕采集实机验证

- [ ] 验证 `libX11.so.6` 在主流发行版上的 ABI。
- [ ] 验证 24bpp、32bpp、大小端和不同 RGB mask。
- [ ] 验证单显示器、双显示器和不同缩放比例。
- [ ] 验证显示器热插拔和分辨率变化。
- [ ] 验证 X Server 重启后的自动重连。
- [ ] 验证长时间监控时内存、句柄和帧率稳定。

完成标准：Ubuntu/Debian、openEuler、麒麟或 UOS 中至少各完成一次 X11 实机验证；采集失败时返回真实错误，不回退为误导性的“正常画面”。

### 3. Linux 音频实机验证

- [ ] 验证 PipeWire 麦克风采集。
- [ ] 验证 PulseAudio 麦克风采集和播放。
- [ ] 验证纯 ALSA 麦克风采集。
- [ ] 验证系统声音回环采集。
- [ ] 验证教师端播放到扬声器、耳机和蓝牙设备。
- [ ] 验证默认声卡切换、多声卡和设备拔插。
- [ ] 验证 PipeWire/PulseAudio 服务重启后的自动恢复。
- [ ] 验证不同发行版的命令参数和设备名称差异。

完成标准：音频设备断开、服务重启后能自动恢复或给出明确错误；不得持续显示“正在采集”但没有数据。

### 4. Linux 多网卡和自动重连

- [ ] 验证有线网卡、Wi-Fi、VPN 和虚拟网卡同时存在时的选择策略。
- [ ] 验证教师端监听地址绑定行为。
- [ ] 验证 UDP 广播发现和组播在多网卡环境中的路由选择。
- [ ] 验证网卡断开、恢复和网络切换后的 KCP 自动重连。
- [ ] 验证防火墙放行教师监听端口、广播和组播流量。
- [ ] 增加日志显示实际使用的本地地址、网卡和发现方式。

完成标准：网络切换后学生端能够自动重新加入正确频道；不会因为绑定了错误网卡导致持续离线。

## P1：平台功能完善

## 当前明确限制

- 当前开发机是 Windows，Linux 测试二进制只能交叉编译，不能在本机直接执行。
- 未在真实 Linux X11、Wayland、PipeWire 或 PulseAudio 机器完成端到端验证前，不宣称 Linux 屏幕采集和音频采集已经生产可用。
- 当前正式构建目标是 `amd64`、`arm64` 和 `loong64`，不能据此宣称覆盖所有国产 CPU。
- 鲲鹏、飞腾通常对应 `arm64`；龙芯 3A 对应 `loong64`；兆芯、海光通常对应 `amd64`；申威需要单独确认 Go 工具链支持情况。
