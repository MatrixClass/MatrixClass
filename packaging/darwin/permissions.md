# MatrixClass macOS 权限说明

这是 macOS 发布骨架阶段的权限说明，最终权限引导页会在 Darwin 原生能力实现后补充。

| 能力 | 用途 | 当前状态 |
| --- | --- | --- |
| 屏幕录制 | 屏幕广播和屏幕监控 | `.app` 已声明用途；真实 ScreenCaptureKit 后端尚未在本阶段实现 |
| 麦克风 | 课堂语音和音频通信 | `.app` 已声明用途；真实 CoreAudio 后端尚未在本阶段实现 |
| 辅助功能 | 远程鼠标、键盘和滚轮 | 本阶段不请求、不绕过 |
| 自动化 | 仅在明确需要控制其他应用时使用 | 本阶段不请求 |

打开位置：系统设置 → 隐私与安全性。权限被拒绝或撤销时，后续原生能力必须返回明确错误，不得伪造成功状态。
