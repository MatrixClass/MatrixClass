# MatrixClass macOS 权限说明

这是 MatrixClass macOS 原生能力的权限说明。源码已提供对应适配器；发布前仍需在实际 Intel 与 Apple Silicon 设备上完成授权和功能验证。

| 能力 | 用途 | 当前状态 |
| --- | --- | --- |
| 屏幕录制 | 屏幕广播和屏幕监控 | 已实现 CoreGraphics/ScreenCaptureKit 动态适配；需要用户授权并完成真机验证 |
| 麦克风 | 课堂语音和音频通信 | 已实现 CoreAudio AudioQueue 适配；需要用户授权并完成真机验证 |
| 辅助功能 | 远程鼠标、键盘和滚轮、快捷键管控 | 已实现 CGEvent 适配；需要用户授权并完成真机验证 |
| 自动化 | 仅在明确需要控制其他应用时使用 | 本阶段不请求 |

打开位置：系统设置 → 隐私与安全性。权限被拒绝或撤销时，后续原生能力必须返回明确错误，不得伪造成功状态。
