# MatrixClass WebDoc

MatrixClass 的独立文档网站，采用原生 HTML、CSS 和 JavaScript 实现，不依赖构建工具即可预览。

## 本地预览

在 `repo/webdoc` 目录执行：

```powershell
python -m http.server 4173
```

然后打开 <http://localhost:4173>。

## 页面

- 首页：项目定位、核心能力和快速入口
- 快速开始：教师端、学生端安装和首次配置
- 教师端：频道、设备视图、广播、文件、作业和远程命令
- 学生端：首次启动、托盘设置、消息和提交作业
- 网络与部署：KCP、频道 ID、跨平台部署和权限
- 常见问题：断线重连、无画面、文件传输和密码问题
- 开发指南：测试、构建、CI 和目录规范
